Jump to a project's GitHub issues or pull requests straight from the sidebar.

## What you get

- A sidebar thread list grouped by project. Hover a project header for
  **Issues**, **Pull requests**, and **New thread** icons.
- Thread rows with status dots (working, needs input, unread), relative times,
  a pinned section, and "Show more" for long projects.
- A **GitHub links** page and a homepage section listing every project's links.

## How it works

The plugin reads each project's git remote. HTTPS, `git@`, and `ssh://` GitHub
remotes work; projects without a GitHub remote get no links. Nothing leaves
your machine and no account or token is needed.

## Note

It replaces bb's thread list while enabled. Choose the built-in list again under
Settings → Appearance → Sidebar, or disable the plugin.
